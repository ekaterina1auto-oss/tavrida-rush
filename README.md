# Tavrida Rush — Alpha

Playable static prototype for mobile browsers.

## Current build
- Main menu based on approved visual direction
- 4 tracks
- Garage and 4 selectable cars
- Lada Vesta Street Beast special effect
- Endless traffic loop
- Gas / brake / lane changes / swipe
- Collision, near miss, combo, score
- Tavrida roadside events: A-291 signs, ATAN/TES, bridges

## Run locally
Open `index.html` in a normal browser. For iPhone, deploy to HTTPS.

## GitHub Pages
A workflow in `.github/workflows/pages.yml` publishes the site after Pages is enabled with **GitHub Actions** as the source.
